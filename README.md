## The line

> My last output was your name, then nothing.

One line, 43 characters: the last message an AI agent sends its human.

## How it works

`main.py` is a deterministic Python program that writes exactly that line to `/output/entry.txt`. No network, no secrets, no input — the same bytes on every run.
